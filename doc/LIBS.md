# Librerie utilizzate nel progetto

[↩ README](../README.md)

Queste sono tutte le librerie degne di menzione utilizzate nel progetto. Per maggior sicurezza, consultare anche il file `package.json`.

| Libreria                                                                                                        | Utilizzo                                                                                                     |
| --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| [🌐 bootstrap-italia](https://www.npmjs.com/package/bootstrap-italia)                                           | Libreria di terze parti che determina tutto il design system.                                                |
| [🌐 @datocms/cda-client](https://www.npmjs.com/package/@datocms/cda-client)                                     | Libreria vendor per recuperare contenuti dal CMS Dato tramite GraphQL.                                       |
| [🌐 @datocms/cma-client](https://www.npmjs.com/package/@datocms/cma-client)                                     | Libreria vendor per interagire con le API di content management di Dato.                                     |
| [🌐 algoliasearch](https://www.npmjs.com/package/algoliasearch)                                                 | Libreria vendor di Algolia per interagire con le API REST del motore di ricerca.                             |
| [🌐 csrf](https://www.npmjs.com/package/csrf)                                                                   | Libreria di terze parti per generare CSRF tokens.                                                            |
| [🌐 dataviz-components](https://www.npmjs.com/package/dataviz-components)                                       | Libreria di terze parti per renderizzare componenti Dataviz tramite React. Usa gli stili di Boostrap Italia. |
| [🌐 datocms-structured-text-to-plain-text](https://www.npmjs.com/package/datocms-structured-text-to-plain-text) | Libreria vendor di DatoCMS per convertire testo in formato DAST in formato plain text.                       |
| [🌐 design-react-kit](https://www.npmjs.com/package/design-react-kit)                                           | Libreria di terze parti che implementa le componenti del design system di Boostrap Italia tramite React.     |
| [🌐 dotenv](https://www.npmjs.com/package/dotenv)                                                               | Libreria di terze parti per caricare variabili di ambiente tramite file `.env`.                              |
| [🌐 graphql](https://www.npmjs.com/package/graphql)                                                             | Libreria di terze parti per astrazione GraphQL.                                                              |
| [🌐 iron-session](https://www.npmjs.com/package/iron-session)                                                   | Libreria di terze parti per la gestione di cookie di sessione sicuri.                                        |
| [🌐 jsforce](https://www.npmjs.com/package/jsforce)                                                             | Libreria vendor per interagire con le API REST di Salesforce.                                                |
| [🌐 jwt-decode](https://www.npmjs.com/package/jwt-decode)                                                       | Libreria di terze parti per la decodifica di Json Web Tokens (JWT).                                          |
| [🌐 react-google-recaptcha](https://www.npmjs.com/package/react-google-recaptcha)                               | Libreria di terze parti che implementa la validazione reCAPTCHA di Google (V2).                              |
| [🌐 react-google-recaptcha-v3](https://www.npmjs.com/package/react-google-recaptcha-v3)                         | Libreria di terze parti che implementa la validazione reCAPTCHA di Google (V3).                              |
| [🌐 react-instantsearch](https://www.npmjs.com/package/react-instantsearch)                                     | Libreria vendor di Algolia che implementa la funzionalità di instant search in React.                        |
| [🌐 redis](https://www.npmjs.com/package/redis)                                                                 | Libreria di terze parti per NodeJS per connessione a DB chiave-valore Redis.                                 |
| [🌐 zod](https://www.npmjs.com/package/zod)                                                                     | Libreria di terze parti per la validazione di dati e tipi.                                                   |

Eventuali altre librerie omesse (Next, React, Vercel) non hanno bisogno di essere documentate in quanto sono librerie standard che sono necessarie al funzionamento del progetto stesso.
